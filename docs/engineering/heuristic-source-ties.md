# Equally relevant source excerpts

The offline heuristic currently keeps one highest-scoring complete sentence per
research target. When two source copies have equal relevance but different
figures, gather order alone can suppress the second copy. The retained R11
policy-conflict workload reproduces this: both documents are read, while only
one contributes an admitted excerpt and an exported reference.

The change retains at most two distinct source markers at the same
highest positive lexical score for each target. A strictly better sentence
replaces all previous ties; repeated sentences from one marker occupy one slot.
Exact arXiv version filtering, complete sentence boundaries, quote offsets and
measured support remain mandatory. No support floor is introduced.

These are source excerpts, not a detected or resolved contradiction. The existing
evidence ledger still decides which excerpts can enter the answer and which
creators can receive rewards. An additional admitted citation can change
attribution; unchanged source-selection decisions do not establish economic
equivalence. Reading, spending, custody and settlement authority stay with their
existing layers.

Twenty-four matched runs on the twelve retained questions admitted both R11
copies instead of one, including both exported references. They did not change
source read attempts or fix the R09 comparison, R13 factual-quote ranking or R14
changed-limit gaps. Five other reasoning methods remained identical, including
source decisions and attribution.

A candidate from the controlled-study worker completed all
48 offline trials with zero outbound attempts. Twelve trials changed citations
and simulated reward distribution: additional excerpts from the primary source
received part of the existing citation pool. Across the matrix, fixture-defined
fact matches rose from 30 to 42. Every source proposal, read and re-evaluation,
fetch total and citation total remained identical; every budget bound held.
This does not establish semantic accuracy or live economic equivalence.

These are offline supplied-snapshot and synthetic-fixture results, not production
search, customer acceptance, complete synthesis or provider cost/latency evidence.
The local implementation passes 120 focused extraction, version, relevance and
evidence-ledger controls, application/operational typechecks and scoped lint.

actual outputs separately. Its artifact schema remains version 1 and records
baseline revision 3 explicitly. The CLI writes only v3 and refuses any drift in
the accepted v1/v2 data and reports, allowing Git CRLF/LF normalization only.
Rewriting an existing v3 also requires identical protocol and actual trial rows;
only reproduced source/lock fingerprints may refresh without a new baseline.
Historical v2 source/lock manifests are frozen with those bytes; v3 independently
binds the current source closure and lock. All original v1-to-v2 economic equality
assertions remain, alongside 67 passing study, archive-integrity and boundary
tests. Required exact-source PR/main CI remains pending.
