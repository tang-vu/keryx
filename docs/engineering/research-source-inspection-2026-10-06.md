# Read-only source inspection — October 6, 2026

The owner requested a deep Tameion assessment, potential user/team portraits and
one memorable small interaction, then explicitly requested an autonomous goal.
The current outreach priorities remain literature-review writers and web3 analysts;
the broader persona hypotheses are retained privately, not reported as customers.

Existing citation drawers, evidence matrices, portable receipts and receipt deltas
already explain sources and money. Add one different operation: temporarily omit
a source from the recorded excerpt view. Reuse the existing evidence matrix gate
in a pure helper; render it in the shared web answer component. No network, model,
payment, database, grant or public schema changes occur.

## Acceptance

- Preserve the original report and all payment/confidence/coverage fields.
- Match target text/index, marker, source and exact recorded article/version.
- Honor explicit answer rejection and the historical qualification fallback.
- Exclude demo labels and known fingerprints, including shared synthetic markers.
- Deduplicate an identical source/article/version/quote within a target; retain
  distinct versions, and omit every version of a selected source.
- Separate newly missing from originally missing excerpts and unavailable history.
- Normalize a foreign or no-longer-inspectable selection to the original view.
- Use semantic labels, native source selection, live status and a keyboard-accessible
  restore action. Wrap titles/quotes and provide minimum 44px action targets.
- Escape stored content. No new telemetry, permalink parameters or source requests.

Focused hermetic logic, static-render and jsdom interaction checks cover these
behaviors. TypeScript, lint and the production build are release checks; exact-head
CI and review, deployment identity and Canteen product reporting close the release.
Browser permission denied direct live/local visual inspection in the originating
session. jsdom validates interaction semantics, not screenshots, responsive layout,
screen-reader output or real-world usefulness. Keep those evidence limits explicit.

## Boundary and rollback

Research targets and excerpt membership do not establish assertion entailment or
factual truth. The current schema does not bind every sentence in historical output;
this release does not fade prose or recompute the answer. The original caption and
payment drawer remain accessible. Do not call source counts independent publishers.

Minimal caller-funded/private results lack the complete identity graph and retain
their existing views. The API, CLI, remote/stdio MCP, desktop, extension and bot
roles are audited in [the user-facing guide](../research-source-inspection.md).
Only hosted web presentation changes; no package/installer upgrade is inferred.

Rollback is removal of the answer-component import/insertion; the pure helper and
tests can remain. No persisted record, migration, custody, financial policy or
original paid operation needs reversal. Runtime deployment must preserve all
current finite holds, protected source/storage bindings and existing schedules.
