# Preserve the complete prepared mainnet build profile

The earlier keyless preparation passed only connector IDs and registry addresses.
It omitted the current Registry v3/origin allowlist, WalletConnect project ID,
withdrawal block window and private-run build flag. These omissions could change
compiled signing/login behavior and remove the configured dispatch privacy
headers. Release 0.27.91's candidate was therefore superseded before production;
the retained 0.27.89 runtime continues serving while preparation is qualified.

App **0.27.92**, stdio MCP **0.4.40** and desktop **0.4.38** preserve the native
historical-receipt fix from release 0.27.91 and add strict preparation admission.
The builder accepts fourteen explicit public compilation values. An eight-field
JSON workflow input supplies the additional controls; unknown keys, malformed
origins, mismatched server/browser twins and unsupported public database settings
refuse before commands. Runtime keys, provider credentials, storage manifests and
allowances remain outside the builder.

Preparation records the public-profile digest and checks the actual compiled
dispatch headers. The standalone reviewed role reader derives only a digest from
the protected runtime ENV, compares it with preparation, and checks artifact
headers before admission. Retained older receipts remain unchanged and cannot
be relabeled as passing the new gate. No registry, withdrawal, signing, storage,
spending or custody authority changes.

Preparation tests keep their SQLite files and browser screenshots in isolated
scratch directories so they cannot contaminate the candidate's closed source
inventory. Unknown source entries still refuse, with their path retained for
diagnosis. The native writer CLI test accepts an early closed input pipe only
while still requiring the real exit and exact structured refusal; runtime writer
behavior is unchanged.

Web/API/hosted MCP and bots inherit the admitted hosted cohort. CLI/stdio MCP,
desktop and extension retain their existing hosted handoffs and custody roles.
Hosted MCP **0.3.19** and extension **0.1.4.3** are unchanged. Publication does not
establish an actual local desktop installation or production runtime delivery.
Keep the website serving throughout install/check/build and candidate acceptance;
maintenance is only for the qualified short handover and necessary fast checks.
