# Popular-language literature search and sort previews

The partial Spanish, Brazilian Portuguese, French, German, Japanese, Korean,
Hindi, Indonesian, Russian and Arabic previews now include eight neutral search
and sort labels each. Each draft remains bound to the existing English source,
with `machineDraft` and `review: null`. Each partial catalogue has 541 authored
entries. The shipped default remains English; this does not provide human
translation approval or complete product-language coverage.

Search scope, privacy and metadata guidance retain their existing English
fallback. The publication-year option also retains English under the existing
conservative preview filter. Their language and direction are attributed at the
authored UI boundary, including left-to-right English in Arabic. Native sort
values and all English source wording stay unchanged.

The browser acceptance exercises the actual component, browser store, local CSS,
fonts and generated catalogues at phone and desktop widths, Arabic direction and
enlarged text. It checks localized controls and selection outside a search,
all four view orders, search/clear/filter interaction, exact filtered RIS and
CSL-JSON output, original-order CSV/JSON backups, unsaved notes and query input,
and absence of storage writes or outbound requests. This fixture performs no
provider research, paper reading, purchase or settlement.

Stored paper identities, metadata, notes, screening values, saved order, locks,
export formats and the shared preview renderer/filter retain their existing
authority. Full applicable PR/platform/domain and exact-main CI, current original
review and normal owned cleanup remain required. Runtime delivery belongs to the
existing ROOT/Circle batch; this source change performs no deployment.
