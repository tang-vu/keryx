# Portuguese classroom proposals

A public history review found a Portuguese lesson request that retained factual
weather/climate excerpts but delivered no requested activity, classification
examples or exit question. The original teaching contract admitted English and
Vietnamese only. Recognizing Portuguese answer presentation did not admit a lesson.

The extension admits a finite explicit original Portuguese request: one activity
lasting 1–30 minutes, 1–4 classification examples, one final question with its
answer, a 1–200 word explanation bound, and explicit labeling of the activity and
examples as the assistant's proposals. `menos de 100 palavras` means at most 99
whitespace-delimited explanatory words. The count excludes verbatim source
excerpts, proposal text and operational notices; it is not a whole-answer limit.
Numeric counts and a limited set of spelled-out counts are supported. Unrecognized
forms remain inactive. Conflicting, quoted, source-attributed, negated and positive
source-performed requests are refused by the finite grammar.

The existing `KERYX_TEACHING_PROPOSALS=1` opt-in, original-question binding and
public, first-turn, attended research admission remain required. Private jobs,
bounded packages, targeted/paid scholarly reads, decision briefs, augmented turns
and unattended engines retain their existing boundaries. This source work does
not activate the flag or change production configuration.

The existing factual generation and independent review calls also generate and
review prospective proposals. Proposal additions can change input and output
token use within the existing teaching caps. No separate proposal call, retry,
provider request, source read or payment authority is introduced. Each proposal
needs the original premise references, scope/language/source-attribution review
and final admitted factual statements. Missing premises or rejected review leave
the dependent proposal out. Proposed examples do not establish that NASA or any
other source tested an activity. They cannot supply factual coverage, citation
admission, attribution or creator rewards.

Portuguese labels, conditions, answers and gap explanations use the existing
literal Markdown escaping. Portable surface, report and receipt projections use
the same request schema, original question hash, language-specific label and final
statement checks. The additive `pt` request language does not relabel historical
answers, enroll language provenance or certify whole-answer language consistency.
Older readers that do not support it may reject the optional teaching projection.
The unchanged factual answer and receipt/payment contracts remain authoritative.

Controlled tests use the observed caller text with synthetic planning, facts,
proposals, reads and reviewer judgments. They compare identical-question runs with
only the new selector disabled, check factual/financial invariants, and exercise
review, scope and portable-projection failures. These are contract tests, not fresh
model quality, classroom effectiveness, deployed delivery or customer acceptance.
The frozen study's complete 48 trial objects and four archived originals must
remain unchanged when its source-closure metadata is refreshed.

Web/API, desktop, CLI, remote/stdio MCP, extension and bot result consumers inherit
the existing optional proposal projection and exported answer within their current
roles. No public ask field, storage schema, version allocation, release, deployment,
funding renewal or schedule is part of this source change.
