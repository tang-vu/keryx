# Preserve completed reads when synthesis is unavailable

October 7, 2026, application 0.27.12 candidate. A paid read can complete while
decision-brief preparation, generation or review cannot produce an accepted
result. Previously these exits returned the same empty result, and the final
answer said the read content supplied no qualifying excerpts. Unavailable
assessment cannot establish that the documents lack evidence.

## Result and authority

The brief engine records only the application-controlled failed stage: bounded
input preparation, generation or review. A thrown synthesis call whose internal
stage is unknown retains that uncertainty. No raw error, provider body, draft,
private context, source name or new factual assertion enters the diagnostic.
Valid generation with no facts and valid negative review remain assessed results,
not transport/preparation failures. Input overflow retains the original cap and
complete selected material; no trimming or second generation is introduced.

The streamed trace and final answer explain retained read count and direct the
reader to review delivery using the original job and receipts before another
paid request. Empty target sections say evidence assessment was unavailable.
The follow-up preserves pending/unknown-payment review priority. Original access
charges survive; evidence, citation admission, creator rewards, exact micro-USDC
allocation and original recovery authority retain their existing gates.
