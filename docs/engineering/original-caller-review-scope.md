# Keep caller conditions available to ordinary evidence review

An accepted noncomparison plan can put a condition only in `constraints` while
returning a shorter factual target. The current target array does not retain that
separate field. A current-code synthetic reproduction produced identical verifier
packets for requests with opposite provider-idempotency conditions. This proves a
reachable information loss, not a historical model failure or measured quality rate.

The existing ordinary evidence-review packet carries the complete unchanged
authorized question passed to synthesis, alongside the existing target and exact
source neighborhood. This includes already-admitted follow-up context; it does
not fetch another conversation or grant a new privacy role. Caller premises define
scope and remain unverified; they cannot override the reviewer or prove a fact.
An explicit source refutation remains valid evidence against a caller premise.

The same 32KB input cap includes the request, existing guidance and framing reserve.
Neither the question nor source context is clipped. Missing, malformed or oversized
ordinary request context grants no review indexes. Whole rows that cannot fit retain
the existing withholding behavior. No extra generation, review, repair or retry call
is added, and token/provider ceilings remain unchanged. Actual token use can change
within those bounds; no billing saving or semantic-success rate is claimed.

Legacy/private/retained producers ignore this ordinary-only field and keep their
previous packet bytes and prompts. Quote identity, complete offsets, source version,
support/language judgments, creator eligibility and exact payment authority remain
separate gates. The shared engine serves its existing web/API/MCP/CLI/bot roles;
desktop and extension transports require no new public field or distribution version.

Controlled checks cover exact caller retention, incompatible conditions, bounded
UTF-8 packets, refusal and private packet compatibility. These are information
preservation checks, not historical model replay or independent semantic validation.
The current-study source closure must preserve all 48 whole trials and four original
archives. Actual full/native/domain/platform/build PR and exact-main acceptance
remain required before source completion.
