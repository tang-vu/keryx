can now select Russian generated prose. The finite selector accepts positive
commands at a clause boundary. Quoted instructions, source titles, negations,
regional tags and Cyrillic text alone do not establish a Russian request. Later
eligible English or Russian commands retain the existing last-command precedence.
Retained and legacy original-request grammars, count limits and budget rules remain
unchanged. Russian does not enable an English word budget.

The ordinary renderer, PDF limits, reading recovery, reports, bot controls and
neutral client wrappers have Russian machine drafts. They retain missing evidence,
partial reading, unavailable synthesis and model-review limitations. No human
translation approval is asserted. The six canonical research financial strings,
bot payment/funding/pause notices, email settlement/ownership prose and browser
review boundary retain their existing English authority.

The independent statement reviewer may report exact `ru` observations. Requests,
system locale labels and JSON self-reports cannot grant output-language evidence.
Existing runtime observation binding and final-answer hashes still reject missing,
mismatched, cloned, mutated or fabricated observations. Ukrainian, Belarusian and
ambiguous Cyrillic prose remain `UNKNOWN`; no local script heuristic is added.
Original quotes, topics, URLs, identifiers, versions, receipts and machine fields
remain literal. Reading and reward eligibility are separate.

Web answer examples, public metadata/OG labels, API schemas, remote and stdio MCP,
CLI, Desktop, extension and bot consumers share the finite presentation support.
Russian citation counts use Russian plural forms, including 2/4, 11 and 21/22.
The authenticated recipient/preference and privacy boundaries are unchanged.
Discord registration source includes the new choice; registration is not executed.
The public web UI locale registry is unchanged: Russian is not a prepared UI locale,
and the shipped UI remains English. This outcome does not create a Russian payment
glossary, translate a payment screen, publish packages or deploy production.
The two existing Vietnamese/Chinese bot-language help entries are rebound to the
new English language list and regenerated. Every other compiled lookup is exact;
their 6,367 authored entries and 29 preserved identifiers remain unchanged.

Focused acceptance covers actual generation and independent review, grounded
rendering and excerpt degradation, observed-language transport and final metadata,
original-byte preservation, recovery, authenticated bot preferences and financial
fallbacks. Chromium uses the actual AnswerMarkdown renderer at 320/1366 pixels and
asserts computed 18/27px prose, citation keyboard activation, separate `ru`/`und`
tags and no external traffic. Actual local-font OG/glyph renders cover Cyrillic,
including Ё/ё. Full exact-head CI and hosted visual review remain merge gates.
