# Ordinary original bibliography tasks — October 8, 2026

Source candidate for issue218. The existing free `paper_lookup` role remains
separate. These helpers supply an ordinary exact-original metadata task to the
shared agent; root owns its result, receipt, renderer and caller integration.
Helpers alone do not complete that activation or close the issue.

## Original caller scope

`recognizeBibliographicTask` receives only the validated original caller question,
before decomposition. It recognizes narrow positive English, French or Vietnamese
instructions requesting a bibliographic/metadata record, title, first author or
first three authors, and an identifier for one explicit DOI or versioned arXiv
abstract-page identity. Exact original French arXiv and later Crossref questions
are retained separately as owner-operated fixtures. No original outcome is edited.

Quoted/code examples, negated instructions, multiple identities, query/fragment
URLs, unversioned arXiv, PDF/full-paper targets, positive scientific-method/result
requests, unsupported language/count forms and incomplete scans do not activate
this path. Recognition is limited, not general intent/language understanding.
Refusal leaves the original task to ordinary research; it does not silently
discard scientific dimensions. Known negative limitations such as “do not
summarize results” remain distinct from a positive request for results.

The frozen process-local capability retains requested fields, author count,
metadata language, exact identity and original-question SHA256. Source text,
model output, parent context, serialized JSON, structural casts and proxies do
not create a task. Root must omit this opt-in for protected private originals.

## Transport and result boundary

The default raw-original reader accepts only canonical HTTPS versioned arXiv
abstract URLs or exact Crossref works URLs. It reuses the public-address-pinned
transport with250000bytes,8000ms, zero redirects and exact expected media type.
It preserves head metadata instead of passing through generic article-body
extraction. Unsupported identity/media/UTF-8, unavailable transport and field
conflicts remain explicit gaps. Cancellation propagates; no retry, supplier
fallback, shared catalog refresh or database write is added.

The existing bounded parser records original field paths/raw units, original
author slots, exact version/DOI, actual observation time and body hash. Page status
is literal when explicitly observed; peer review remains unknown. The result is
`kind:bibliography`, `scope:metadata-only`, with the record, deterministic language
labels and separate BibTeX/RIS. It contains no ordinary scientific evidence,
citation, coverage, confidence, attribution, creator payment or settlement claim.
An abstract-page identity does not establish a full-paper read. Missing fields or
failed reads do not produce invented references or a request for full paper merely
to supply displayed metadata.

## Integration and acceptance

Root's shared-agent integration must preserve original admission, cancellation
and any already-paid service obligation while making no model/search/source
purchase/reward call for this branch. Keep metadata records/exports separate in
saved runs, portable receipts, public API/MCP and web/CLI/desktop result consumers.
No source metadata may be restored into a citation or payment authority.

Helper tests cover both frozen French tasks, supported English/Vietnamese forms,
language/count/scientific/quoted/negated refusals, capability restoration, raw
head retention, exact transport bounds, substitution/media/UTF-8 refusal,
cancellation, field gaps and separate exports. Captured fixtures and synthetic
transports do not prove actual original-provider usefulness, independent users,
deployment or published surface synchronization. Coordinated result/receipt
tests, both TypeScript graphs, lint/build/CI and deployed original-task acceptance
remain root's release gates. No paid live call is authorized or performed here.
