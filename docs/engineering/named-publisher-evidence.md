# Named publisher evidence eligibility

A frozen caller question requests official MDN documentation for an HTTP
explanation. The current ledger can accept an exact, complete off-site quote with
a high model score despite that requirement. The existing discussion-page gate
correctly rejects forums but does not reject an unrelated blog. A synthetic
current-source reproduction isolates this gap without a new source/model call.

The additional negative gate recognizes finite, unambiguous original-caller
requests for official documentation or exclusive sources from MDN, NASA or NOAA
in English, Vietnamese, Portuguese and Spanish. Quoted/code/source-attributed
instructions cannot create the requirement. Prepared envelopes, conflicting,
mixed, unknown and unsupported forms keep their existing handling. A supplied
different origin leaves a mixed request unclassified; the parser does not choose
one publisher for the caller.

An incompatible or uninspectable final item URL cannot qualify its evidence,
answer citation, coverage or creator reward. Source names and model-created
targets cannot create this restriction or satisfy it. The parser runs once per
ledger. Every existing exact-span, version, provenance, support and final-review
gate still applies. The canonical renderer uses only accepted ledger evidence.

The namespace references are [MDN](https://developer.mozilla.org/en-US/about),
[NASA](https://www.nasa.gov/about/) and
[NOAA](https://www.noaa.gov/about-our-agency). Matching a hostname is not proof of
authorship, document identity, official-document role, truth or task completion.
Exact-document and discussion-role checks remain separate. An allowed host does
not grant a citation or payment permission.

This focused gate acts after existing reads and reviews. It does not restrict
upstream discovery/read-slot selection, repair a failed original, add a retry or
refund an already settled access fee. Existing source-owned payout identity,
integer reward allocation, hard caps, signatures, reservations, reconciliation
and delivery accounting retain their authority. New model/provider/payment trials
and deployment are outside this source change.
