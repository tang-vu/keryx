# Explicit bullet-count delivery

Public question review found direct Vietnamese requests for exactly three or at
most four bullets receiving the longer target layout without a count notice.
The existing short-bullet parser is retained. A separate finite English and
Vietnamese parser recognizes explicit exact/maximum directions in the original
caller question. Quoted/code spans, attributed instructions, negation, conflicting
counts and unsupported counts cannot select this new projection. This is a
conservative instruction grammar, not general natural-language understanding.

Only the ordinary public producer participates. Private, targeted, prepared,
execution-limited and teaching paths retain their existing behavior. An existing
whole-answer word limit or sentence-note contract keeps priority. Recognizing a
bullet count does not establish compliance with another word limit; in particular,
this change does not add Vietnamese whole-answer word counting.

The original factual generation/review packets and canonical attribution answer
remain unchanged. After final evidence review, the renderer prepares a candidate
using the existing exact statement/quote bindings, original targets, support
floors, source/item/URL/version identities and grouping limits. No fact, quote,
qualification, accepted marker or target may be dropped to fit a count. Maximum
means one through N natural groups, not exactly N; exact counts are never padded.

Only final delivery, after attribution and settlement, can apply the projection.
It retains the original confidence warning and every later operational/payment
notice. The final list-row count includes supplied-original status and mandatory
follow-ups. If the candidate cannot meet the bound, the complete target layout
and an explicit count notice remain. An early/no-source result is also unmet.
The `≤ N` label reuses existing translated notices without calling a maximum an
exact number. No language enrollment or human translation review is inferred.

The saved answer, reports and receipt answer digest inherit the final rendering;
the digest proves byte integrity, not factual truth or usefulness. There is no
new model call, retry, search/read, funding, custody, execution, public ask field,
storage schema, package version or deployment authority. Tests use controlled
model/reviewer responses and synthetic facts; no fresh live task-success claim.
