# A direct homepage ask path

Issue [#539](https://github.com/tang-vu/keryx/issues/539) reduces the decisions a
first-time reader sees before asking. The question, Quick/Deep, Ask Keryx, examples,
short payer sentence and actual publication notice stay beside the composer.
Budget/model, visibility, scholarly search, review-first, metadata lookup and
search disclosure share one initially closed **More options** control. The
existing tour opens it for the budget step. Mainnet omits paid manuscripts;
testnet retains the existing funded-session control.

The input accepts a provisional draft while visibility loads. Submission still
requires the server selection, matching wallet and current identity revision.
Owner changes discard the old draft. Same-owner revalidation still hides an
existing private draft until the context is confirmed. A failed context request
shows an error beside Ask, with the existing retry in More options. Editing an
automatic shared-link question cancels that automatic submission.

The short free-trial sentence applies to the treasury payer. Funded, expired and
unavailable sessions retain their status/recovery instructions. Exact six-decimal
caps remain inside the budget disclosure. Public-link copy follows the returned
visibility; private/unlisted selections show their actual notice instead.

The homepage retains How it works, product proof, creator information and FAQ.
Activity and the Product Hunt badge follow How it works; its walkthrough link is
inside that section. The overview/setup components and their routes remain.
Desktop and mobile share Ask, Past answers and Sources as primary navigation;
all previous secondary destinations remain under More tools. The footer retains
saved reports and the protected account-claim research entry.

## Surface boundaries and acceptance

- Web homepage and shared web composer/header/footer receive the composition
  change. The protected account-claim route and other research pages retain their
  own empty-state guidance, grants, follow-ups, stop and new-research controls.
- API, CLI, remote/stdio MCP, native desktop, extensions and bots keep their
  existing request/publication/payment contracts. This change adds no endpoint,
  signing, funding, spending, custody or scheduling authority.
- Regression coverage exercises closed/open controls, mainnet/testnet manuscript
  visibility, retained values and exact submit arguments, visibility failures and
  retries, owner changes, shared links, navigation and a submitted question.
- New/changed English invalidates only the affected VI/ZH draft leaves and
  namespace bindings. Unreviewed translations fall back to English; no locale
  activation or translation approval is claimed.

This outcome has no version bump, package publication or production deployment.
After review and required CI, merge the focused PR and hand the runtime change to
the existing release coordinator for the next deployment batch.
