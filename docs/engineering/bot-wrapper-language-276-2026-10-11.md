# Original-question bot notices — issue276 source checkpoint

This candidate localizes product-owned Telegram, Discord and Slack research
wrappers using the same bounded original-question selector as ordinary answers.
The supported answer roles are English (`en`), Vietnamese (`vi`), Brazilian
Portuguese (`pt`, explicitly mapped to `locales/pt-BR`) and Spanish (`es`).
Unsupported output directives keep the selector's English fallback. This is
neither general language detection nor a shipped interface locale switcher.

The shared typed catalogue owns citation headings, weight labels, zero/one/many
source labels, recorded creator totals, settlement caveats, full-trace links,
treasury/sponsored-limit notices, progress and failure framing. A product-owned
research pause is localized with its existing public meaning. Provider and
source diagnostic details retain their original bytes, subject to each bot's
existing escaping and truncation. They may therefore remain in another language.
Bare help commands and malformed commands have no admitted original question or
stored preference; their English copy is extracted without changing delivery.

Selection is request-local: the saved run's original question selects result
copy, and the parsed command's original question selects early notices and
failures. Source excerpts, answer statements, confidence and gap text, receipt
fields, URLs and command names are not translated or rewritten. Citation amount
formatting, weight values, raw `real`/`offline`/`legacy` payment modes and budgets
retain their prior contracts. A planned or recorded reward never establishes
settlement; the localized wrapper directs the reader to the original receipts.

Bot authentication, sponsored admission, treasury funding, origin/provenance,
ephemeral responses, Telegram private preflight, claim-token generation and
sender-private packet delivery are unchanged. The existing Telegram account-claim
preflight placeholder remains English; this checkpoint deliberately does not
edit that credential/privacy module. No preference persistence, ordinary-schema
admission, native enrollment, funding or schedule is added.

English source and target notices are agent-authored. No human translation
approval, trust-glossary approval or deployed localization is claimed. Human
review of financial/trust prose remains work for issue273 and full localization
acceptance; this bounded issue276 increment does not mark those translations
reviewed or satisfy that work. It does not consume the gated trust glossary or
activate the UI locale foundation. Its partial source release requires independent
review, exact combined hosted CI and verified delivery, without inventing a
standalone human-approval gate for ordinary bot notices. The UI enabled-locale
list is unchanged.

## Verification and delivery boundary

original-question selection, unsupported/negated/ordered directives, concurrent

canonical amounts/modes, bot caps and controller admission order. Existing bot
parsing/signature, paused-research and private account-claim delivery regressions
remain applicable. Fixtures mock bot transport and providers; no messages, model

handlers. Shared answer generation, API/MCP/CLI/desktop/extension runtime cores
and package metadata are unchanged. Source import inspection, focused tests,
app TypeScript and scoped lint qualify this checkpoint; no new compiled bundle
