# Free public relevance for long offline questions

The retained twelve-task replay on current source still selected no original in
six tasks. For example, the long SQLite task assigned the relevant Online Backup
API title only about 7% query-word overlap and skipped its zero-cost original.
This is a limitation of the deterministic offline engine, not measured production
model or live-search quality.

For an otherwise skipped, zero-cost public original, the heuristic now also
measures how much of its short title matches a single research target. At least
two topic words must match. Generic document labels alone do not qualify. Both
candidate and item must be public references, with an HTTP(S) original URL and
no credentials; marketplace/creator offers and explicit arXiv-version tasks keep
their prior policy. Transport and exact-document checks still decide whether the
original can actually be read. This metadata score cannot create evidence.

Already positive proposals keep their exact old values and targets. An initial
experiment rescored these too and lost a counterpart read in the frozen PDF
comparison; that experiment was rejected. Preserving them retains that read.
The existing read/attention limits, portfolio, budgets, extraction bounds,
evidence/reward thresholds and settlement paths are unchanged. Adding free
candidates can change which alternatives the portfolio selects; identical paid
decision proposals are not a promise of identical live economic outcomes.

The matched candidate recovered a read in four of the six previously empty
tasks, including Stripe webhook documentation, which then contributed a cited
excerpt. Two cases still selected no original, and several newly read tasks
still had no qualifying excerpt. R09/R11/R14 comparisons remain incomplete.
These results do not establish completed checklists or recommendations, accuracy,
customer usefulness or vendor cost/latency savings.

Qualification uses the same frozen questions, supplied discovery candidates and
reader snapshots. Only this heuristic module differs across the 548 project
inputs. Three hundred paid/creator/inconsistent-kind/marketplace controls retain
exact decision objects, and decomposition, sufficiency, reevaluation, synthesis
and attribution methods remain exact. Replays deny outbound network and child
execution and use an in-memory database and refusing payment gateway. Required
source/domain CI, the controlled-study refresh and coordinated release authority
remain separate gates. No live provider call, payment or deployment is admitted.
