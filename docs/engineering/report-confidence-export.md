# Recorded confidence in portable reports

Copied and downloaded research reports retain the stored confidence level and
reason alongside the original answer. The formatter uses the existing report
heading selected from recorded answer-language provenance; it does not infer a
new assessment or language from the question or current viewer. Level values and
recorded reasons stay unchanged, with scalar text escaped for safe Markdown.

The assessment is the agent's recorded evaluation of its answer, not a factual
guarantee, independent review or settlement proof. Confidence calculation,
coverage, source grouping, citations and reward eligibility remain unchanged.
Older reports without an assessment do not receive a fabricated Low assessment.
Their original answer and existing limitations remain available.

The same formatter serves the actual report Copy and Download controls. No model
request, new read, purchase, receipt mutation, historical backfill or new response
field is involved. API/CLI/MCP projections keep their existing confidence fields
and supported roles. Payment evidence still distinguishes pending, simulated,
settled and unverified records using the original payment data.

Regressions cover all three levels with each of the thirteen recorded-language
headings, missing historical confidence, hostile rationale text, and actual
clipboard/download bytes. These controlled checks establish export fidelity,
not independent answer usefulness or improved confidence scores.
