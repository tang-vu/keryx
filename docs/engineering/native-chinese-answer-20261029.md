# Simplified Chinese ordinary answers and presentation

This source adds canonical `zh-Hans` to ordinary answer delivery alongside `en`,
`vi`, `pt`, `es` and `fr`. `pt-BR` remains a request alias of `pt`. UI previews,
answer intent, observed answer language and human translation approval retain
separate authority. Selecting a Chinese UI preview does not request an answer in
Chinese or establish the language of an existing answer.

## Intent and evidence

An explicit original-question instruction such as “请用简体中文回答。” or
“Answer in Simplified Chinese.” selects the admitted ordinary producer. Generic
Chinese output requests use Simplified Chinese. This bounded grammar checks
clause boundaries, quoted spans, negation and last-positive precedence; it is not
a general language detector. A later unsupported Traditional Chinese instruction
clears earlier supported intent. Existing retained and legacy producer grammars
are unchanged. English word budgets and Spanish sentence notes keep their scopes;
safe short bullets either preserve every target and excerpt or refuse compacting.

Generation guidance precedes the existing independent evidence-review call. That
same bounded call can observe `zh-Hans`; Traditional, mixed, ambiguous or missing
observations are `UNKNOWN`. A request, synthesis property, unbound record or clone
does not establish observation authority. Wrong-language statements are withheld
without promoting or discarding separately admitted source evidence.

Native ordinary delivery covers reviewed summaries, excerpt-only output,
unavailable synthesis, gaps, compact layouts, confidence, API integration notes,
supplied-original status and manual reading recovery. Original targets, source
text, URLs, identifiers, citation markers and qualifications remain literal.
PDF notices reuse the existing source-bound machine draft and observed page/text
scope. They do not claim OCR, image interpretation or whole-document coverage.
Recovery suggestions initiate no read, supplier call, purchase or automatic retry.

Private, execution-limited package, teaching and other separately admitted
producers keep their existing opt-in boundaries. A final language packet requires
the actual renderer and every delivered reviewed statement to agree, then binds
the exact final UTF-8 bytes. Additional unobserved operational/payment prose still
prevents whole-answer language proof. Stored and completed readers retain closed
schemas, query binding and canonical codes: `zh`, `zh-CN`, `zh-Hant` and `pt-BR`
are not observed-language evidence. No history is relabelled or backfilled.

## Client and financial boundaries

CLI/Desktop system labels use the explicit or maximized script from `Intl.Locale`:
Hans selects Simplified Chinese; Hant and Taiwan/Hong Kong/Macao defaults do not.
This selects labels only. Explicit client overrides remain finite request codes.
Bot platform hints use the same script-aware rule; an answer preference requires
an authenticated, recipient-scoped explicit command and successful readback.
Original-question output intent takes precedence over that internal preference.

Public API/MCP `language` and CLI/Desktop presentation controls remain labels-only.
They do not enter generation input, signed paid bodies/hashes, query identity,
funding or recovery. The installed MCP test adds a Chinese vector while retaining
the exact question/body/hash, source evidence, receipt and custody/recovery checks.
The separate free `paper_lookup` bibliography language enum is unchanged.

Canonical English financial, funding, settlement, pause, review-boundary and
critical email prose remains authoritative. Email translates navigation only;
recipient rotation and settled-only delivery retain their existing gates. There
is no new signer, nonce, allowance, budget, source eligibility, payout authority,
reservation, settlement state or retry. Source-owned payTo and exact integer
micro-USDC accounting remain authoritative. Native rendered answers still enter
the existing model attribution call, so identical live weights are not promised.
Fixed synthetic allocations test the preserved arithmetic and authority instead.
