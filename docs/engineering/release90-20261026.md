# Research desk and private library release

This batch ships the accepted research desk, archive, evidence, citation and source
reading improvements together with saved-report comparison and private literature
tools merged after release 0.27.89. Report comparison matches saved evidence and
exports a deterministic comparison plan; it does not run another paid research job.
Private literature adds sorting, bulk screening, selected offline exports, backup
inspection/comparison and recovery guards for unsaved edits and library removal.
Reading fixes preserve HTML section anchors and clip Unicode text safely.

The release identities are app **0.27.90**, stdio MCP **0.4.38** and desktop
**0.4.36**. Hosted MCP remains **0.3.19** and the unchanged extension remains
**0.1.4.3**. These are source identities until exact-main CI, publication and the
existing ROOT deployment procedure establish delivered identities.

| Surface | Change and retained role |
| --- | --- |
| Web | Research desk, archive, evidence matrix, citation drawer, report actions, source catalogue and reading controls; saved-report comparison and private library tools. |
| API and hosted MCP | Existing research, evidence, receipt and original-requester contracts; shared reader fixes. No new hosted signing or settlement action. |
| CLI and stdio MCP | Saved-report comparison, private literature export and backup inspection/comparison; bounded regular-file inputs and strict JSON/receipt verification. Publish the exact-source tool bundle. |
| Desktop | Existing task, receipt, export and buyer handoff roles; publish the accepted exact-source installer and bundled helper. Publication does not establish a local installation. |
| Extension | Existing thin hosted API/listing handoff; extension bytes and version unchanged. |
| Bots | Existing shared hosted research/report behavior and dispatch links. |

Payment, custody, registry authority, main database/schema, Operator holds and
held schedules keep their existing controls. Preserve the independent requester
opinion journal, all pending originals, live financial state and required recovery
copies. This release adds no funding, allowance renewal, autonomous schedule,
pilot invitation or App54 execution. Read-only acceptance establishes source,
availability and recovery compatibility; it makes no new paid-usefulness or
traction claim.
