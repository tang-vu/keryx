# Report a wrong UI translation / Báo lỗi bản dịch / 反馈界面翻译错误

## English

Preview translations are machine drafts (`machineDraft`), not human-reviewed.
Critical consent, payment and legal text stays in canonical English. English is
the authoritative interface. The web app offers the following previews after
its language controls load; an older deployed version may offer fewer choices.
This guide does not enable a preview or establish production delivery.

| Language | Code | Draft coverage |
| --- | --- | --- |
| English | `en` | Canonical interface |
| Tiếng Việt | `vi` | Broader interface draft; some English remains |
| 简体中文 | `zh-Hans` | Broader interface draft; some English remains |
| Español | `es` | Navigation, question labels, getting started and neutral product/About copy |
| Português do Brasil | `pt-BR` | Navigation, question labels, getting started and neutral product/About copy |
| Français | `fr` | Navigation, question labels, getting started and neutral product/About copy |
| Deutsch | `de` | Navigation, question labels, getting started and neutral product/About copy |
| 日本語 | `ja` | Navigation, question labels, getting started and neutral product/About copy |
| 한국어 | `ko` | Navigation, question labels, getting started and neutral product/About copy |
| हिन्दी | `hi` | Navigation, question labels, getting started and neutral product/About copy |
| Bahasa Indonesia | `id` | Navigation, question labels, getting started and neutral product/About copy |

The eight newer previews have 150 authored presentation entries each, including
all 95 source-bound entries in the product guide. The current preview boundary
admits 49 of those product-guide keys; the other 46 retain English. Authored
payment, privacy, consent and legal drafts still require human review before use.
These remain partial translations: account workflows, reports, installation instructions and
other untranslated text retain English. A preview choice changes interface copy;
it does not translate original questions, source evidence, saved answers or
payment records, or select the language of a research answer.

1. Note the **Interface language** choice currently shown: **Tiếng Việt (preview)**
   (`vi`), **简体中文 (preview)** (`zh-Hans`), **English** (`en`), or a native
   language name from the table above followed by **(preview)**.
   Say which explicit preview you are using and where you opened it. If no preview
   is offered, or English appears instead, say so; do not infer it from your browser language.
2. Name the page and label/button. Copy the current UI wording, suggest better
   wording, and briefly explain the intended meaning or context.
3. If useful, attach a screenshot of public UI with sensitive data removed.
   Never share wallet or session keys, seed phrases, private questions or paid
   content. Redact a copy; keep original reports, receipts and other authoritative
   evidence unchanged.
4. Use the existing [Keryx repository Issues page](https://github.com/tang-vu/keryx/issues)
   (also linked from About). With your existing GitHub access, look for a matching
   report or choose **New issue**. Include the details above and a title such as
   “UI translation: vi — navigation label”.

A suggestion is not approval. Human approval requires a real, named reviewer
and a recorded review under the [translation instructions](translation-instructions.md).
No author or agent approval is claimed for these drafts or this guide.

## Tiếng Việt

Bản dịch xem trước là bản nháp máy dịch (`machineDraft`), chưa được người
duyệt. Nội dung quan trọng về chấp thuận, thanh toán và pháp lý vẫn dùng bản
tiếng Anh chính thức. Tiếng Anh là giao diện có thẩm quyền; các lựa chọn xem trước
và phạm vi dịch được liệt kê ở bảng trên. Các bản dịch mới bao phủ điều hướng,
nhãn của biểu mẫu hỏi, phần bắt đầu sử dụng và các đoạn giới thiệu sản phẩm trung tính.
Mỗi ngôn ngữ mới có 150 mục nháp, bao gồm đủ 95 mục của phần hướng dẫn sản phẩm;
chỉ 49 mục trong phần này đủ điều kiện xem trước, 46 mục còn lại vẫn dùng tiếng Anh.
Một phần giao diện vẫn dùng tiếng Anh; đủ bản nháp không đồng nghĩa đã được duyệt.
Ngôn ngữ giao diện và ngôn ngữ câu trả lời là hai lựa chọn riêng. Hướng dẫn này không bật bản xem trước.

1. Ghi lựa chọn đang hiển thị ở **Interface language**: **Tiếng Việt (preview)**
   (`vi`), **简体中文 (preview)** (`zh-Hans`) hoặc **English** (`en`).
   Nêu rõ bản xem trước bạn đang dùng và nơi bạn mở bản đó. Nếu không có lựa chọn
   xem trước hoặc giao diện hiện tiếng Anh, hãy ghi đúng như vậy; đừng suy ra từ
   ngôn ngữ trình duyệt.
2. Nêu trang và nhãn/nút bị sai. Chép nguyên văn chữ trên giao diện, đề xuất
   cách viết tốt hơn và giải thích ngắn gọn ý nghĩa hoặc ngữ cảnh.
3. Nếu cần, đính kèm ảnh chụp giao diện công khai đã xóa thông tin nhạy cảm.
   Không chia sẻ khóa ví, khóa phiên, cụm từ khôi phục, câu hỏi riêng tư hay
   nội dung trả phí. Che thông tin trên bản sao; giữ nguyên báo cáo, biên lai
   và các bằng chứng có giá trị xác thực gốc.
4. Dùng [trang Issues của kho mã Keryx](https://github.com/tang-vu/keryx/issues)
   (cũng có liên kết từ About). Với quyền truy cập GitHub sẵn có, tìm báo cáo
   tương tự hoặc chọn **New issue**. Ghi các chi tiết trên và đặt tiêu đề như
   “UI translation: vi — nhãn điều hướng”.

Đề xuất sửa không phải là phê duyệt. Việc phê duyệt cần người duyệt thật, có
tên cụ thể và bản ghi đánh giá theo [hướng dẫn dịch](translation-instructions.md).
Không có tuyên bố phê duyệt của tác giả hay tác nhân AI cho các bản nháp hoặc hướng dẫn này.

## 简体中文

预览翻译是机器草稿（`machineDraft`），尚未经人工审核。涉及同意、
付款和法律的重要文字仍使用具有权威性的英语原文。英语是权威界面语言；
预览语言及翻译范围见上表。新增预览涵盖导航、提问表单标签、入门内容和中性的产品介绍。
每种新增语言有 150 条草稿，包括产品指南的全部 95 条原文；其中 49 条可用于预览，
其余 46 条仍使用英语。草稿完整不代表通过人工审核。部分界面仍为英语。
界面语言与研究回答语言是独立的选项。本指南不会启用预览。

1. 记录 **Interface language** 中当前显示的选项：**Tiếng Việt (preview)**
   （`vi`）、**简体中文 (preview)**（`zh-Hans`）或 **English**（`en`）。
   说明你正在使用哪个明确标为预览的版本，以及在哪里打开它。如果没有预览
   选项，或实际显示英语，请如实说明；不要根据浏览器语言推断。
2. 写明页面和有问题的标签或按钮。抄录当前界面文字，提出建议用语，
   并简要说明原意或使用场景。
3. 如有帮助，可附上已移除敏感信息的公开界面截图。不要分享钱包或会话密钥、
   助记词、私人问题或付费内容。请在副本上遮盖信息，保留原始报告、
   收据及其他具有权威性的证据，不要修改原件。
4. 使用现有的 [Keryx 仓库 Issues 页面](https://github.com/tang-vu/keryx/issues)
   （About 页面也有链接）。使用已有的 GitHub 访问权限，查找类似反馈，
   或选择 **New issue**。填写上述信息，标题可用
   “UI translation: zh-Hans — 导航标签”。

修改建议不等于批准。人工批准必须由真实、具名的审核者按照
[翻译说明](translation-instructions.md)留下审核记录。本指南及这些草稿
均未声称获得作者或 AI 代理的批准。
