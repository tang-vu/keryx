# Next Canteen event: pre-kickoff baseline

Prepared September 24, 2026. The next event has not started. Its public RFP,
eligibility, dates, submission format, and judging criteria are not recorded here;
verify them from the organizer before choosing a track or making event claims.
Lepton and Agora rules are historical and must not be reused as current rules.

## What Keryx already has

- A live Arc **testnet** reading agent with visible source decisions, paid x402
  fetching, evidence-gated citation rewards, and Circle Gateway settlement.
- Public Ledger, Proof, answer archive, creator registry, paid agent endpoint,
  and source-owned payouts. The Ledger separates independently initiated use
  from Keryx-operated activity. Testnet USDC is not mainnet revenue.
- Buyer quote/buy/resume tooling, payment reconciliation, a private operator
  economics report, and an illustrative public business calculator. Private
  operating estimates are not public traction or verified profit.

## Work worth doing before kickoff

1. **One independent buyer journey.** Have a buyer using their own testnet
   wallet quote, buy, resume, read the answer, and inspect the receipt. Record
   failures and support needed as carefully as successful settlement. Do not
   turn an owner-operated run into independent demand.
2. **One independent creator journey.** Verify feed ownership, publish useful
   content, receive a citation reward, inspect pending versus settled earnings,
   and complete a cash-out. Retain the source and transaction evidence.
3. **Business measurement.** Join package receipts, creator obligations,
   latency, quality, and repeat use by buyer cohort. Keep actual provider bills
   and operating costs private; mark missing inputs unknown. See
   [mainnet delivery](./mainnet-delivery-plan.md) for the acceptance map.
4. **Operational rehearsal.** Confirm health, tunnel recovery, remaining VPS
   disk space, backup restore, and rollback on the intended release. A live URL
   and a status badge alone do not prove the service is recoverable.
5. **Short reviewer path.** Rehearse Ask → decision trace → cited answer →
   creator payment → proof in a fresh browser, including a narrow mobile view.
   Show the independent/first-party split and testnet label without explanation
   from the founder.

## At kickoff

- Save the official RFP, rules, start/end times, and eligibility source links.
- Capture the exact deployed commit and a dated settled-only metrics snapshot.
  Record independent and Keryx-operated activity separately, along with pending
  payments and known data limits.
- Keep a dated log of **new** product changes and independently initiated use
  during the event. Do not count this pre-event baseline as event progress.
- Reprioritize this checklist against the actual rubric; do not assume an
  event requires mainnet. Mainnet spending remains separately gated.
