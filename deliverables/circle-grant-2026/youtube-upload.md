## Title

Keryx — Every Citation Pays Its Creator | Circle x Arc Technical Demo

## Description

Keryx is a citation-toll reading agent. Given a question and a budget, it discovers sources, explains BUY/SKIP/CACHE decisions, buys selected x402 content, synthesizes a cited answer, and settles weighted USDC rewards to the creators it actually cites.

This technical demo walks through the production code and a real Arc testnet dispatch powered by Circle USDC, Agent Stack / Gateway Nanopayments, x402, and Unified Balance Kit. Current production metrics are settled-only; first-party autonomous volume is separated from independently initiated usage.
